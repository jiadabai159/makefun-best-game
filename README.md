NEON VOID — a neon arena survival shooter. Fly a lone ship through the swarm, blast drones, darts, brutes, spitters and splitters, collect shards, level up and pick upgrades, and slay the Dreadnought boss on wave 5 — then again on wave 10 to win the campaign. Endless flight after that.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network: the game is static files under game/.

WASD / arrows to fly, mouse to aim, hold click or Space to fire. P pauses, M mutes, R restarts, 1 / 2 / 3 picks a level-up card.
